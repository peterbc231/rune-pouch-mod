# Rune Pouch

A portable pouch designed specifically for **Advent of Ascension (AoA3)** staves.

[![Modrinth](https://img.shields.io/badge/Modrinth-Rune%20Pouch-green)](https://modrinth.com/project/rune-pouch)

## Features

- 27 slots (3x9) rune storage
- Curios API integration (charm slot)
- AoA3 Archmage enchantment support
- Nightmare armor set bonus compatibility
- Custom texture, Chinese & English language support

## Requirements

- Minecraft 1.16.5
- Forge 36+
- Curios API (required)
- AoA3 3.6.11 (required)
